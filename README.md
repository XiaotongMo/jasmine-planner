## 📌 项目简介

**jasmine-planner** 是一款开箱即用、以“每日记录”为核心的电子手帐。它将 **To-Do List（待办）**、**Timeline（24小时时间轴）** 和 **Habit Tracker（习惯追踪）** 三大效率工具无缝集成在一个优雅的单页视图中。

项目基于原生 JavaScript 与 Supabase 后端构建，支持多端云端数据同步，旨在为你提供无打扰、高掌控感的每日规划体验。

---

## ✨ 核心特性与亮点

- **☁️ 云端数据防丢失**：集成 Supabase Auth & Database，支持邮箱登录，保障数据私密与安全。
- **⚡ 双模式同步**：支持**自动防抖保存（被动同步）**与**一键手动提交（主动同步）**，改动实时云端响应。
- **📊 24小时可视化 Timeline**：以 0.5 小时（30分钟）为最小粒度，支持多日程**重叠/并行放置**及拖拽缩放。
- **🔄 跨日期日程复制**：一键拉取历史日期的 Timeline 配置，极大提升例行日程的填写效率。
- **🌱 习惯无缝继承**：新的一天自动延续前一日的习惯项目及打卡维度，重置完成状态，无需重复创建。
- **🖨️ 原生打印优化**：针对 `window.print()` 进行了专门的 CSS 打印样式适配，隐藏操作栏与冗余 UI，轻松导出纸质版或 PDF 归档。

## 📖 详细功能与操作指南

> 💡 **交互小贴士**：为了确保在移动端或触摸屏上的顺畅体验，手势上下滚动建议在**功能区外的白缝空白区域**进行。

### 1. 🧭 顶部控制栏 (Header & Actions)
* **日期切换**：点击 `◀` / `▶` 按钮或直接点击日期选择框，可快速调取不同日期的记录。
* **强制同步**：点击 `☁️ 同步保存` 可立刻绕过防抖延迟，将当前视图强行上传至云端。
* **打印/导出**：点击 `🖨️ 打印` 可将当前页面格式化导出为纸质手帐或 PDF 文件。

### 2. ✅ 上区：To-Do List（待办事项）
* **创建/删除**：在底部输入框输入内容并按 `Enter` 快速添加；点击右侧 `✕` 移除。
* **完成状态**：点击待办左侧的圆圈（Bullet），可在“未完成（空心）”与“已完成（实心+划线）”状态间切换。

### 3. ⏳ 中区：Timeline（24小时时间轴）
* **创建与编辑**：点击时间轴上的任意半小时网格即可生成新日程，直接点击文本区域可自由修改事项名称。
* **时间拉伸**：激活日程块后，拖拽**上边框**或**下边框**的滑块即可调整开始与结束时刻（按 0.5h 步长吸附）。
* **并行/重叠日程**：点击日程块左右侧的 `+` 按钮，可在此时间段增加并行任务，**同一时段最多支持 3 个日程重叠**。
* **标签管理**：点击 `⚙️ 管理标签` 可自定义不同分类的名称与高亮背景色；点击标签可快速切换当前选中的日程颜色。
* **批量复制**：点击 `📋 复制其他日期`，输入目标日期（如 `2026-03-30`），可一键将该日的 Timeline 全部覆盖至当前页面。

### 4. 🌱 下区：Habit Tracker（习惯追踪）
习惯打卡支持三种自由搭配的维度：
1. **勾选框**：记录是否完成（如：早起打卡）。
2. **数字框**：记录量化指标（如：饮水量 `2000` ml、阅读 `30` 页）。
3. **文本框**：记录心得或详细备注（如：跑姿感受、心情）。

* **无缝延续**：当切换到未记录的新日期时，系统会自动向云端检索**前一日的习惯列表**，保持名称不变并清空勾选/数值，方便直接开始新一天的打卡。
